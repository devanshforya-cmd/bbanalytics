# Nepal administrative locations

The 77 districts and 753 local levels in `municipalities.json` are bundled for offline search. The app also offers a user-entered location for neighborhoods and other places outside this list.

Source: [nepali-canonical](https://github.com/ritushishir/nepali-canonical), revision `3a85560226491d9fc45cc639b66fc799e16f41c6`, by ritushishir and contributors. Distributed under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/); the full license is in [LICENSE.txt](LICENSE.txt). The JSON is copied without modification; the app creates searchable labels and adds province suffixes at runtime.

The seven province names and display labels are supplied by this application. The source cites Nepal's [local-level portal](https://sthaniya.gov.np/gis), and its counts match the [National Statistics Office local-level reference](https://ec.nsonepal.gov.np/html/admin_code.html). English spellings and administrative names can change, so update the bundled dataset when corrections are published.
